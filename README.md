

# frida-repos
Collect Frida related projects for learning only

## Contents
- `codeshare/`: Frida scripts for hooking OkHttp3, bypassing SSL pinning, handling SQLite, and intercepting crypto operations.
- `common/`: Utility functions for type conversion, field inspection, process naming, and remote Frida execution.
- `modify/`: Advanced hooks for method overloads, `RegisterNatives`, and class tracing.
